2. Dati Raccolti e Tipologie di Trattamento

Archivio Semantico è progettato secondo i principi di privacy by design e di minimizzazione dei dati. I dati raccolti sono limitati a quanto strettamente necessario per l'autenticazione sicura dell'utente e la gestione del proprio schedario personale:

  • Dati di Autenticazione (Google Sign-In / Firebase Authentication): Quando l'utente sceglie di accedere tramite il pulsante "Accedi con Google", riceviamo da Google Identity esclusivamente i seguenti dati identificativi di base del profilo:
    • Indirizzo email verificato dell'account Google
    • Identificatore utente univoco (Google UID / Firebase UID)
    • Nome visualizzato o nome utente pubblico del profilo
    Questi dati servono esclusivamente a identificare univocamente l'utente ed autorizzarne l'accesso al proprio archivio protetto.
  • Dati dell'Archivio e Schede Personali: I testi delle note, schede cliniche o teoriche di Medicina Tradizionale Cinese, categorie, tag, correlazioni semantiche e impostazioni di visualizzazione sono creati dall'utente. Tali dati vengono memorizzati esclusivamente in locale nel browser dell'utente mediante la tecnologia standard IndexedDB.
  • Dati Tecnici di Sessione: Informazioni temporanee sulla sessione (lingua preferita, tema chiaro/scuro) memorizzate localmente in localStorage del dispositivo dell'utente.

3. Integrazione con le API di Google e Ambito di Autorizzazione (Google Drive)

L'applicazione Archivio Semantico offre una funzionalità opzionale e facoltativa di backup e ripristino cloud tramite Google Drive, ideata per consentire all'utente di preservare in autonomia una copia di sicurezza dei propri archivi.

Ambito di autorizzazione OAuth richiesto:

https://www.googleapis.com/auth/drive.file

Descrizione ufficiale Google: "Visualizzare, creare e modificare i file di Google Drive che hai aperto o creato con questa app".

Dettaglio sull'Accesso Limitato ai File (Principio del Minimo Privilegio)

In conformità allo scope drive.file, dichiariamo in modo vincolante che:

  • Accesso esclusivo ai soli file creati dall'applicazione: L'applicazione accede unicamente ai file di backup generati dall'applicazione stessa, aventi nome formattato come Archivio Semantico - [Nome].json.
  • Nessun accesso ad altri file o cartelle: L'applicazione NON ha la facoltà e NON può in alcun modo visualizzare, leggere, elencare, modificare, condividere o cancellare nessun altro file, documento (Google Docs), foglio di calcolo (Google Sheets), presentazione, immagine o cartella presente nel Google Drive dell'utente.
  • Comunicazione diretta e crittografata: Tutte le operazioni di backup e ripristino avvengono con una connessione diretta e crittografata (HTTPS/TLS) tra il browser dell'utente e le API ufficiali di Google Drive (https://www.googleapis.com/drive/v3/). I file di backup non transitano mai su server intermediari di nostra proprietà.

Divieto di Cessione, Vendita o Uso Pubblicitario (No Commercial Use)

  • I dati dell'account Google dell'utente e i contenuti dei file di backup non vengono MAI venduti, ceduti o noleggiati a terze parti.
  • I dati non vengono utilizzati a fini di profilazione, marketing o targeting pubblicitario.
  • I dati dell'utente non vengono condivisi con broker di dati né con partner commerciali.

Divieto di Addestramento di Modelli di Intelligenza Artificiale

I dati ottenuti tramite le API di Google o presenti nei backup degli utenti non vengono in alcun caso utilizzati per alimentare, addestrare, perfezionare o migliorare modelli di intelligenza artificiale o modelli di machine learning generalizzati.

Dichiarazione Esplicita di Conformità alle Norme Google:
L'uso e il trasferimento da parte di Archivio Semantico di informazioni ricevute dalle API di Google a qualsiasi altra applicazione sono rigorosamente conformi alle Norme relative ai dati utente dei servizi API di Google (Google API Services User Data Policy), compresi i requisiti di utilizzo limitato (Limited Use requirements).

4. Conservazione, Sicurezza e Gestione dei Token

  • Conservazione in Memoria Volatile dei Token OAuth: Il token di accesso Google OAuth (access token) ottenuto durante l'accesso viene conservato unicamente in memoria volatile (RAM del browser) per la durata della sessione e decade alla chiusura o alla disconnessione dell'utente. Il token non viene salvato in cookie né in archiviazione permanente non protetta.
  • Crittografia in Transito: Tutte le trasmissioni di dati avvengono mediante protocollo crittografato HTTPS con certificati TLS 1.3 aggiornati.
  • Local Storage e IndexedDB: I dati dello schedario risiedono nel database IndexedDB protetto dal sandboxing di sicurezza del browser web del dispositivo dell'utente.

5. Revoca dei Permessi e Modalità di Cancellazione Dati

L'utente mantiene in ogni momento il pieno ed esclusivo controllo sui propri dati personali e sui permessi concessi ad Archivio Semantico.

Come revocare l'accesso di Google Drive:

  1. Dall'interno dell'applicazione: Aprire il menu in alto a destra, selezionare la voce "Backup su Google Drive" e cliccare sul pulsante "Scollega Google Drive".
  2. Dalla pagina di sicurezza del proprio account Google: Visitare in qualsiasi momento la pagina di gestione delle autorizzazioni Google:
    https://myaccount.google.com/permissions
    Individuare "Archivio Semantico" nell'elenco delle applicazioni di terze parti e selezionare "Rimuovi accesso". La revoca ha effetto immediato sui server Google.

Come cancellare i propri dati:

  • Cancellazione delle schede locali: L'utente può eliminare singole schede o interi archivi dall'interfaccia dell'applicazione, oppure cancellare la cache e i dati del sito dal proprio browser.
  • Cancellazione dei file di backup da Google Drive: L'utente può eliminare in qualunque momento i file Archivio Semantico - *.json accedendo direttamente al proprio Google Drive (drive.google.com) o svuotando il cestino di Drive.
  • Cancellazione definitiva dell'account Firebase: Per richiedere la cancellazione completa e irreversibile dell'account e di qualsiasi identificativo associato dai database di autenticazione, è sufficiente inviare un'email a:
    gestsocialgabriele@gmail.com
    La richiesta verrà elaborata e confermata entro un massimo di 30 giorni lavorativi senza costi aggiuntivi.
